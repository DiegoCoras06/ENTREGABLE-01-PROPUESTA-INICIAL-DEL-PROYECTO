# Propuesta Inicial del Proyecto - Gestión del Proceso de Admisión

## Integrante

Diego Alejandro Coras Bendaño

## Descripción

Propuesta inicial de una solución de software para la gestión del proceso de admisión universitaria.

El sistema permitirá gestionar las principales actividades relacionadas con el proceso de admisión, incluyendo el registro de postulantes, inscripción, selección de modalidad y programa de estudios, gestión de información del postulante, generación de documentos y consulta de resultados.

## Caso de estudio

Sistema de gestión del proceso de admisión universitaria, tomando como referencia funcional el Portal de Admisión de la Universidad Nacional de San Cristóbal de Huamanga (UNSCH).

## Curso

Arquitectura de Software

## Etapas del proyecto

### Etapa 1: Análisis del sistema

En esta etapa se identifican:

* Actores.
* Historias de usuario.
* Requisitos funcionales.
* Atributos de calidad.
* Restricciones.
* Drivers arquitectónicos.

### Etapa 2: Diseño arquitectónico inicial

En esta etapa se realiza una primera propuesta de organización de la solución mediante una arquitectura en capas, identificando:

* Capa de presentación.
* Capa de lógica de negocio.
* Capa de datos.
* Módulos principales.
* Dependencias.
* Sistemas externos.
* Diagrama de arquitectura inicial.
