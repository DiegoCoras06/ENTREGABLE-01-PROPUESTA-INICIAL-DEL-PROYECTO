# Requisitos funcionales

## Sistema de Gestión del Proceso de Admisión

| ID   | Requisito funcional                                                                              |
| ---- | ------------------------------------------------------------------------------------------------ |
| RF01 | El sistema debe permitir registrar los datos personales del postulante.                          |
| RF02 | El sistema debe permitir validar los datos de identificación del postulante.                     |
| RF03 | El sistema debe permitir registrar y actualizar la información académica del postulante.         |
| RF04 | El sistema debe permitir consultar y seleccionar las modalidades de admisión disponibles.        |
| RF05 | El sistema debe permitir consultar y seleccionar los programas de estudio disponibles.           |
| RF06 | El sistema debe permitir registrar una inscripción al proceso de admisión.                       |
| RF07 | El sistema debe permitir validar la información registrada antes de confirmar la inscripción.    |
| RF08 | El sistema debe permitir generar un código único de postulante o inscripción.                    |
| RF09 | El sistema debe permitir generar y consultar la ficha de inscripción.                            |
| RF10 | El sistema debe permitir descargar los documentos relacionados con la inscripción.               |
| RF11 | El sistema debe permitir gestionar la información de los postulantes al personal autorizado.     |
| RF12 | El sistema debe permitir administrar modalidades y programas de estudio.                         |
| RF13 | El sistema debe permitir gestionar la información del proceso de admisión.                       |
| RF14 | El sistema debe permitir consultar los resultados del proceso de admisión.                       |
| RF15 | El sistema debe permitir enviar confirmaciones y notificaciones relacionadas con la inscripción. |
