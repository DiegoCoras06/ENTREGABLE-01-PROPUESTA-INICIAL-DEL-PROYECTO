# Atributos de calidad

## Sistema de Gestión del Proceso de Admisión

| ID   | Atributo de calidad | Escenario de calidad                                                                                                                                                             |
| ---- | ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AC01 | Rendimiento         | Las operaciones de consulta, registro e inscripción deben responder adecuadamente incluso cuando exista una alta cantidad de postulantes realizando operaciones simultáneamente. |
| AC02 | Disponibilidad      | El sistema debe permanecer disponible durante los periodos establecidos para la inscripción y consulta de información del proceso de admisión.                                   |
| AC03 | Escalabilidad       | El sistema debe poder soportar un incremento significativo de postulantes y solicitudes durante los periodos de mayor demanda.                                                   |
| AC04 | Seguridad           | Los datos personales, académicos y de inscripción de los postulantes deben estar protegidos frente a accesos no autorizados.                                                     |
| AC05 | Mantenibilidad      | El sistema debe estar organizado de manera que permita realizar modificaciones y correcciones sin afectar innecesariamente otros módulos.                                        |
| AC06 | Integridad          | La información de los postulantes e inscripciones debe mantenerse consistente y evitar registros duplicados o inconsistentes.                                                    |
| AC07 | Usabilidad          | El proceso de inscripción debe presentar una interfaz comprensible que permita al postulante completar sus datos y operaciones de manera sencilla.                               |
