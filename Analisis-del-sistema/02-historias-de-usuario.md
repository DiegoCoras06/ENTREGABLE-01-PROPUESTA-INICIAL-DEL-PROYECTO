# Historias de usuario

## Sistema de Gestión del Proceso de Admisión

| ID   | Historia de usuario                                                                                                                                   |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| HU01 | Como postulante, quiero registrar y completar mis datos personales, para realizar correctamente mi inscripción al proceso de admisión.                |
| HU02 | Como postulante, quiero seleccionar mi modalidad y programa de estudios, para participar en el proceso de admisión correspondiente.                   |
| HU03 | Como postulante, quiero realizar y confirmar mi inscripción, para obtener mi registro como participante del proceso de admisión.                      |
| HU04 | Como postulante, quiero consultar y descargar mis documentos de inscripción, para disponer de la información necesaria para participar en el proceso. |
| HU05 | Como personal de admisión, quiero gestionar y verificar la información de los postulantes, para mantener actualizado el registro de participantes.    |
| HU06 | Como administrador, quiero gestionar las modalidades, programas y configuración del proceso de admisión, para mantener actualizado el sistema.        |
| HU07 | Como postulante, quiero consultar los resultados del proceso de admisión, para conocer el resultado obtenido.                                         |
| HU08 | Como personal de admisión, quiero consultar información consolidada del proceso, para realizar el seguimiento y control de las inscripciones.         |
