# Historias de Usuario

## Sistema Integral de Gestión del Proceso de Admisión – UNSCH

| ID | Historia de usuario |
|---|---|
| HU01 | Como postulante, quiero registrar mis datos personales y validar mi identidad mediante RENIEC, para realizar mi inscripción correctamente. |
| HU02 | Como postulante, quiero seleccionar la modalidad Ordinaria o Exonerados y mi programa de estudios, para participar en el proceso correspondiente. |
| HU03 | Como postulante, quiero adjuntar los documentos requeridos, para cumplir con los requisitos de inscripción. |
| HU04 | Como postulante, quiero realizar el pago mediante una pasarela de pagos, para confirmar mi derecho de inscripción. |
| HU05 | Como postulante, quiero consultar el estado de mi inscripción y descargar mi ficha, para realizar el seguimiento de mi participación. |
| HU06 | Como postulante de Exonerados, quiero consultar y subsanar observaciones de mi expediente, para completar mi inscripción. |
| HU07 | Como personal de admisión, quiero gestionar convocatorias, postulantes e inscripciones, para supervisar el proceso de admisión. |
| HU08 | Como evaluador documental, quiero revisar, aprobar u observar expedientes, para verificar el cumplimiento de requisitos. |
| HU09 | Como responsable de tesorería, quiero verificar y conciliar los pagos realizados, para controlar las transacciones de inscripción. |
| HU10 | Como coordinador de exámenes, quiero programar fechas, horarios y sesiones de evaluación, para organizar los exámenes de admisión. |
| HU11 | Como coordinador de exámenes, quiero asignar sedes y aulas a los postulantes, para distribuirlos adecuadamente durante el examen. |
| HU12 | Como postulante, quiero consultar mi sede, aula y horario de examen, para conocer dónde y cuándo debo presentarme. |
| HU13 | Como responsable de resultados, quiero registrar y procesar las calificaciones, para generar los puntajes y órdenes de mérito. |
| HU14 | Como responsable de resultados, quiero publicar los resultados autorizados, para informar oficialmente a los postulantes. |
| HU15 | Como postulante, quiero consultar mis puntajes y resultados, para conocer mi condición de ingreso. |
| HU16 | Como postulante, quiero utilizar un chatbot inteligente integrado con OpenRouter API, para resolver dudas sobre el proceso de admisión. |
| HU17 | Como postulante, quiero consultar mediante el chatbot el estado de mi inscripción, pago y documentos, para recibir seguimiento personalizado. |
| HU18 | Como personal de soporte, quiero atender consultas e incidencias derivadas del chatbot, para solucionar problemas de los postulantes. |
| HU19 | Como postulante, quiero recibir notificaciones sobre pagos, inscripciones, exámenes y resultados, para mantenerme informado. |
| HU20 | Como personal de admisión, quiero consultar reportes y estadísticas del proceso, para realizar el seguimiento de las inscripciones. |
| HU21 | Como administrador, quiero gestionar usuarios, roles y permisos, para controlar el acceso a las funcionalidades del sistema. |
| HU22 | Como administrador, quiero configurar modalidades, programas, vacantes y cronogramas, para administrar los procesos de admisión. |
| HU23 | Como administrador, quiero gestionar las integraciones con RENIEC, pasarela de pagos, OpenRouter y correo electrónico, para garantizar el funcionamiento de los servicios externos. |
| HU24 | Como administrador, quiero consultar los registros de auditoría, para supervisar las operaciones realizadas en el sistema. |
