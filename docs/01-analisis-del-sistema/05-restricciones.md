# Restricciones

## Sistema de Gestión del Proceso de Admisión

| ID   | Restricción             | Descripción                                                                                                                                 |
| ---- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| RC01 | Aplicación web          | El sistema debe desarrollarse como una aplicación accesible mediante un navegador web.                                                      |
| RC02 | Control de versiones    | El proyecto debe gestionarse mediante Git y mantenerse en un repositorio de GitHub.                                                         |
| RC03 | API REST                | La comunicación entre la aplicación web y los servicios del sistema debe realizarse mediante una API REST.                                  |
| RC04 | Base de datos           | La información del sistema debe almacenarse en una base de datos relacional.                                                                |
| RC05 | Validación de identidad | El sistema debe considerar la integración con un servicio externo para la validación de los datos de identificación del postulante.         |
| RC06 | Pasarela de pago        | El sistema debe considerar la integración con una pasarela de pago externa para procesar los pagos correspondientes al proceso de admisión. |
| RC07 | Documentos digitales    | Los documentos generados por el sistema deben poder consultarse y descargarse en formato digital.                                           |
| RC08 | Protección de datos     | El tratamiento de los datos personales de los postulantes debe considerar mecanismos de protección y control de acceso.                     |
| RC09 | Presupuesto             | La solución inicial debe considerar tecnologías y servicios que puedan implementarse con un costo reducido para fines académicos.           |
